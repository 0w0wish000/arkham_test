# 13 · 人工測試檢查表(真人可用性驗收)

> 目的:用**真人**把遊戲從頭玩一遍,判斷「這樣的功能適不適合真人使用」。
> 每項都有 **怎麼做 / 應該看到什麼 / 判定**。判定分兩層:
> **☐ 功能對** (機制有照規則跑) 與 **手感** (看得懂、按得順、不用問人)。
> 手感評分:**😀 順** / **😐 可用但卡** / **😖 不行**。任何 😐/😖 都請寫一句「哪裡卡」。
>
> 本輪範圍:**單場測試劇本(沙盒)**,單人 + 雙人。自動化 e2e 已覆蓋機制正確性,
> 這份專測**真人體驗**:看不看得懂、找不找得到、會不會誤操作、爽不爽。

---

## 0. 測前準備(5 分鐘)

| # | 步驟 | 應該看到 |
|---|---|---|
| 0-1 | 主機執行 `scripts/start/start-server.command`(mac)/ `.bat`(Win) | 終端機印出區網 IP 與「已啟動」 |
| 0-2 | 瀏覽器開 `http://<主機IP>:8080/` | 出現「阿卡姆驚魂記」主選單 |
| 0-3 | 雙人測試時,第二台(或另一個瀏覽器**無痕視窗**)開同一網址 | 同上;兩邊是**不同身分** |

> ⚠️ 同一台電腦測雙人請用**無痕視窗**或不同瀏覽器 —— 身分(playerId)存在 localStorage,同一個視窗會是同一個人。
> ⚠️ 改版後測試前先**硬重新整理**(Mac `Cmd+Shift+R` / Win `Ctrl+F5`),避免用到舊畫面。

## A. 單人流程(A1–A10)

### A1 首次進入 · 身分建立
- **怎麼做**:第一次開頁面,輸入你的名字 → 進主選單。
- **應該看到**:主選單顯示「你好,<名字>」,旁邊有「改名」。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:不用說明就知道這個名字是幹嘛的嗎?(是「玩家名」不是「角色名」)

### A2 開新檔案 · 建桌
- **怎麼做**:「+ 開新檔案」→ 桌名隨意 → 戰役選「🧪 測試沙盒」→ 難度「簡單」→ 建立桌次。
- **應該看到**:進入名冊畫面,看到自己 1 人、標示在線。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:「戰役」「難度」兩個選項看得懂嗎?知道沙盒是測試用嗎?

### A3 選角 + 選卡器
- **怎麼做**:調查員下拉選 Joe Diamond → 再按「🃏 完整選卡器」看一下 → 關掉。
- **應該看到**:名冊上你的角色變成 joe_diamond;選卡器能開、能看到卡池。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:知道「不編牌組也能直接開打」嗎?選卡器關掉會不會怕東西不見?

### A4 開打 · 第一眼
- **怎麼做**:按「✓ 準備完成」。
- **應該看到**:切到戰役板 —— 地圖(圓形排列的地點卡)、左上自己的數據、右上回合小卡、下方手牌。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**第一眼知道現在該做什麼嗎?**(回合小卡有沒有幫到你)左上的 ❤️🧠 大數字看得清楚嗎?

### A5 移動 · 高亮引導
- **怎麼做**:看地圖,找可以走的格子 → 點它移動。
- **應該看到**:相鄰可走的格子有**綠色呼吸外框 + 🚶 角標**,連線也變綠;點了就移動過去。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:不用教就知道「綠框=可以走」嗎?行動用完後綠框消失,你有發現嗎?

### A6 調查 · 技能檢定全流程
- **怎麼做**:在有線索的格子按「🔍 調查」→ 投入面板出現 → 選 0~2 張手牌 → 送出。
- **應該看到**:①投入面板顯示「基礎 X vs 難度 Y」與預估 ②抽混沌標記的動畫 ③成功/失敗彈窗 ④成功則線索 +1。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**看得懂為什麼成功/失敗嗎?**(基礎值、投入加值、抽到的標記)投入面板的「最多可投入」規則清楚嗎?

### A7 打牌 + 啟動能力
- **怎麼做**:手牌點「Field Toolkit」打出 → 它出現在檯面 → **點檯面那張卡**啟動。
- **應該看到**:打出扣資源、卡進檯面;啟動後資源 +2、行動 -1;同一輪再點會被擋並說明原因。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:知道「檯面卡可以點來啟動」嗎?(這件事有沒有任何提示)

### A8 戰鬥 · 敵人資訊與擊敗
- **怎麼做**:走到「訓練場」→ 對訓練假人按「🤝 交戰」→ 連續「⚔️ 戰鬥」到打死牠。
- **應該看到**:敵人卡有**血條 + ❤️N/M**;打中時卡片**震動 + 飄 -N**;血條變短;擊敗時中央飄「☠️ 擊敗 訓練假人!」。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**每一下有沒有打中、扣多少,看得出來嗎?**血條顏色(滿紅→快死綠)會不會誤導?

### A9 挨打 · 受擊回饋
- **怎麼做**:走到「實戰巷」(未揭示的那格)→ 揭示後「實戰教官」會與你交戰 → 故意在交戰中按「🎴 抽牌」吃趁隙攻擊,再直接按「✋ 我打完了」吃敵人階段攻擊。
- **應該看到**:①全螢幕**紅色閃光** + 飄「-1 ❤️」②紫色閃光 + 「-1 🧠」③左上徽章彈跳、數字變色 ④右上回合小卡出現**紅框警示**「你被實戰教官纏住…先閃避或擊敗牠」。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**沒盯著文字 log 也知道自己被打了嗎?**警示有沒有在你按「我打完了」之前就看到?

### A10 閃避 · 教學是否有效
- **怎麼做**:對實戰教官按「💨 閃避」直到成功,然後結束回合。
- **應該看到**:成功後敵人卡**變灰** + 綠徽章「😴 已耗竭 · 本輪不會攻擊、不趁隙」;閃避鈕變停用;紅框警示消失;結束回合**不會挨打**。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**你相信「閃避完就安全」了嗎?**(有沒有被說服)耗竭的視覺(變灰)夠明顯嗎?

## B. 存檔 / 續玩(B1–B3)

### B1 中途存檔
- **怎麼做**:玩到一半按「💾 保存並離開」→ 同意存檔。
- **應該看到**:提示已存檔;回到主選單,「我的本機存檔」出現這一筆(含桌名/章數)。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:知道存檔存在**自己電腦**而不是雲端嗎?看得出存到第幾輪嗎?

### B2 載入續玩
- **怎麼做**:主選單 → 「📂 加載存檔」→ 選剛才那筆 → 載入 → 按「我已就緒」。
- **應該看到**:回到戰役板,**位置、血量、線索、檯面卡、打死的敵人**全部跟存檔當下一樣;事件紀錄有回放。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:載入過程有沒有「不知道在等什麼」的空白期?

### B3 完成一章 · 結算繼承
- **怎麼做**:湊滿 3 個線索 → 按「📖 推進幕」。
- **應該看到**:章節結算播報(獲得經驗)→ 回到牌組大廳,顯示「第 2 章」;存檔自動更新;若你被打過,名冊上會有 🩸/🧠 創傷標記。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**知道自己拿到多少經驗、下一步要做什麼嗎?**創傷會影響下一章這件事有講清楚嗎?

## C. 雙人流程(C1–C8)　需要兩台/兩個無痕視窗

### C1 找到朋友的桌 · 加入
- **怎麼做**:A 建桌後,**B 不做任何事**只看主選單。
- **應該看到**:B 的「進行中桌次」自動出現 A 的桌(桌名、人數、戰役)→ 按「加入」進入同一名冊。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**不用報房號**這件事,B 直覺找得到嗎?

### C2 選角衝突
- **怎麼做**:兩人都試著選 Joe Diamond。
- **應該看到**:後選的人被擋,訊息說「已被隊友選走」;下拉中被選走的角色是**不可選**狀態。
- ☐ 功能對　手感:😀 / 😐 / 😖

### C3 準備屏障
- **怎麼做**:A 先按「準備完成」,等 10 秒,B 再按。
- **應該看到**:A 按完**不會**直接開打(名冊顯示 1/2 就緒);B 按完兩人**同時**進戰役板。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:A 等待時知道「在等誰」嗎?

### C4 自由順序(本作設計特色)
- **怎麼做**:兩人**同時**各自行動(A 調查、B 移動),不互相等待。
- **應該看到**:兩邊都能立刻操作,不會出現「還沒輪到你」;各自的行動數獨立扣。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**兩人同時動會不會亂?**(有沒有搞不清楚誰做了什麼)語音溝通夠不夠?

### C5 協力投入(合作感的關鍵)
- **怎麼做**:兩人站**同一格**,A 按調查 → **B 這邊也會跳出投入面板**。
- **應該看到**:A 面板可投多張;B 面板寫「最多 1 張(協助隊友)」;**兩人都回覆後**檢定才結算,雙方都看到結果。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:**B 知道自己是在幫 A 嗎?**(面板有沒有講清楚是誰的檢定)等待對方回覆時會不會焦慮?

### C6 分頭行動
- **怎麼做**:B 走去別的格子,A 在原地調查。
- **應該看到**:B **不會**再收到 A 的投入面板(不同地點不能協助);兩邊地圖上看得到對方在哪。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:看得出隊友現在在哪一格、狀態如何嗎?

### C7 全員結束回合(屏障)
- **怎麼做**:A 按「✋ 我打完了」,B 先不按,過 10 秒再按。
- **應該看到**:A 的小卡顯示「完成 1/2,等隊友」;B 按完才進敵人/整備階段,而且**階段是一段一段演給你看**(敵人階段 → 整備階段)。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:等待時有沒有煩躁?階段演出速度(約 0.6 秒一段)太快還太慢?

### C8 多人存檔繼承
- **怎麼做**:A 發起「保存並離開」→ 兩人都同意 → **兩人都離開** → 這次改由 **B** 從自己的本機存檔重開 → A 從桌次清單加入 → 兩人都按就緒。
- **應該看到**:兩人本機**都有**存檔;由誰重開都可以;續玩後兩人的角色、位置、戰果都正確。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:「存檔複製到每個人電腦、誰都能開」這個設計,朋友理解嗎?會不會擔心存檔對不上?

## D. 意外狀況(D1–D3)　真人玩一定會遇到

### D1 掉線重連(接手)
- **怎麼做**:遊戲中 B **直接關掉分頁**,10 秒後重開網址進來、從桌次清單加入。
- **應該看到**:名冊顯示 B 掉線;B 回來後**接回原本的調查員**,狀態不變;若他掉線時卡在投入面板,回來會**重新問他一次**。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:A 在等待時知道「B 掉線了、可以等他回來」嗎?

### D2 換裝置 / 清資料(席位認領)
- **怎麼做**:B 用**另一個無痕視窗**(等於新身分)進來,加入同一桌 → 對名冊上「離線的 B」按「🔑 這是我」→ A 同意。
- **應該看到**:投票通過後,新身分**繼承**原本的角色/牌組/經驗/創傷,舊席位消失。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:這個流程對真人來說會不會太複雜?(想像朋友換電腦的情境)

### D3 手牌爆量 · 自選棄牌
- **怎麼做**:連續抽牌讓手牌超過 8 張,然後結束回合(整備會再抽一張)。
- **應該看到**:跳出棄牌面板要你**自己選**棄哪幾張(不是系統亂棄);沒棄完前你**不能行動**,但**隊友照常玩**。
- ☐ 功能對　手感:😀 / 😐 / 😖
- **重點問**:知道為什麼跳這個面板嗎?被擋住行動時有清楚說明嗎?
