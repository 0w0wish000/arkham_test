## 判定與手感定義

| 欄位 | 值 | 說明 |
|---|---|---|
| 判定 | **P** | Pass —— 預期結果全部出現 |
| | **F** | Fail —— 有預期結果沒出現 / 出錯 |
| | **B** | Blocked —— 前置失敗,無法執行 |
| | **N** | Not tested —— 未測 |
| 手感 | **😀** | 順:不用問人、不用猶豫 |
| | **😐** | 可用但卡:做得到但要想一下 / 找一下 |
| | **😖** | 不行:誤解、誤操作、或體驗明顯差 |
| 優先 | **P0** | 阻斷級:壞了就不能玩 |
| | **P1** | 主流程:壞了體驗嚴重受損 |
| | **P2** | 邊緣 / 加分項 |

## 0. 前置作業(每次測試開始前)

| 編號 | 步驟 | 預期結果 | 完成 |
|---|---|---|---|
| PRE-01 | 主機執行 `scripts/start/start-server.command`(mac)/ `.bat`(Win) | 終端機印出區網 IP 與啟動完成 | ☐ |
| PRE-02 | 瀏覽器開 `http://<主機IP>:8080/` | 出現「阿卡姆驚魂記」主選單 | ☐ |
| PRE-03 | 硬重新整理(`Cmd+Shift+R` / `Ctrl+F5`) | 確保不是舊版畫面 | ☐ |
| PRE-04 | 雙人測試:第二台或**無痕視窗**開同一網址 | 顯示為**另一個身分**(不是同一人) | ☐ |

> ⚠️ 同機測雙人**必須**用無痕視窗或不同瀏覽器 —— 身分存在 localStorage,同視窗會是同一人。
