Arkham LCG 一鍵包 —— 使用說明
================================

■ 怎麼開始
  Windows:雙擊 ArkhamStart.bat
  macOS  :雙擊 ArkhamStart.command
           (若被系統擋下:右鍵 → 打開;或在終端機執行
            xattr -dr com.apple.quarantine <解壓資料夾>)

  視窗會啟動遊戲伺服器,幾秒後自動打開瀏覽器 http://localhost:8080/
  輸入名字 → 開新檔案建桌,即可開始。

■ 隊友怎麼加入(同一個 Wi-Fi / 區網)
  啟動視窗會印出你的區網位址,例如 http://192.168.1.50:8080/
  隊友用瀏覽器打開它、輸入名字、在清單按「加入」即可。
  (只有主機一人需要跑本程式,其他人只要瀏覽器。)

■ 防火牆
  第一次啟動 Windows 若跳出防火牆詢問,勾「私人網路」並允許(埠 8080)。

■ 存檔
  對局會自動存檔到 saves/ 資料夾;每位玩家的瀏覽器也各自留一份
  (主選單可載入續玩)。

■ 卡片資料(進階,可跳過)
  基於版權,本包不內含完整卡片文字資料;開箱用內建卡目錄即可遊玩。
  想載入完整卡庫(4,400+ 張):安裝 Python 3(python.org)後,
  在本資料夾開終端機執行:
      python content/tools/build_cards.py
      python content/tools/build_campaigns.py
  完成後重開 ArkhamStart 即生效。

■ 疑難排解
  - 開不起來:埠 8080 可能被占用,關掉占用的程式再試一次。
  - 隊友連不進:確認在同一區網、主機防火牆已放行 8080。
  - 中文顯示亂碼:啟動視窗的文字不影響遊戲,遊戲畫面都在瀏覽器裡。
